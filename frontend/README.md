# PDF Visualization Frontend

A modern React-based web interface for browsing and viewing PDF documents generated by the Speckit Auto-AI backend.

## Features

- 📁 **Project Dashboard** - Browse all your projects
- 📄 **Artifact Browser** - Search and filter PDF artifacts by type
- 🔍 **Search & Filter** - Find documents quickly with search and category filters
- 📖 **PDF Viewer** - View PDFs directly in the browser
- 📚 **Version History** - Access previous versions of documents
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile
- ♿ **Accessible** - WCAG AA compliant with keyboard navigation

## Tech Stack

- **React 18** - UI framework
- **TypeScript** - Type safety
- **Vite** - Build tool and dev server
- **React Query** - Server state management
- **React Router** - Client-side routing
- **shadcn/ui** - UI component library
- **Tailwind CSS** - Styling
- **Axios** - HTTP client

## Quick Start

### Prerequisites

- Node.js 20+ 
- Backend API running on `http://localhost:8000`

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at `http://localhost:5173` (Vite's default port).

### Environment Variables

Optional - `src/config/env.ts` has the same values as built-in fallbacks, so the app runs without any env file. To override, copy the example:

```bash
cp .env.example .env.development
```

```env
VITE_API_BASE_URL=http://localhost:8000
# Must match SPECKIT_EXT_API_KEY on the backend (dev-key by default)
VITE_API_KEY=dev-key
```

## Architecture

### State Management

- **Server State**: React Query for API data fetching and caching
- **Local State**: React useState for UI state

### Routing

Routes are defined in `App.tsx`:

- `/` - Project dashboard
- `/projects/:projectId` - Artifact list for a project
- `/projects/:projectId/artifacts/:artifactId` - PDF viewer (latest version)
- `/projects/:projectId/artifacts/:artifactId/versions/:versionId` - PDF viewer (specific version)

### API Integration

The frontend communicates with the FastAPI backend through:

- `GET /api/projects` - Fetch all projects
- `GET /api/projects/{id}/artifacts` - Fetch artifacts for a project
- `GET /api/artifacts/{id}/versions` - Fetch version history
- `GET /api/doc-versions/{id}/pdf` - Download PDF

## Deployment

### Static Hosting (Netlify, Vercel, Cloudflare Pages)

1. Build the project: `npm run build`
2. Deploy the `dist/` folder
3. Configure SPA routing (all routes → index.html)
4. Set environment variables in hosting dashboard

### Docker

```dockerfile
FROM node:20 as build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/nginx.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

## Troubleshooting

### Backend Connection Issues

**Problem**: "Backend server is not available"

**Solution**:
- Ensure backend is running on `http://localhost:8000`
- Check `VITE_API_BASE_URL` in `.env.development`
- Verify CORS settings in backend allow `http://localhost:5173` (see `backend/app/main.py`)

### API Key Issues

**Problem**: "Authentication failed"

**Solution**:
- Check `VITE_API_KEY` in `.env.development`
- Ensure API key matches backend configuration

### Build Errors

**Problem**: Type errors during build

**Solution**:
```bash
# Clear cache and reinstall
rm -rf node_modules dist
npm install
npm run build
```
