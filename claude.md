# Claude Code Migration Guide

## Project Overview

**Project**: Speckit Auto-AI - PDF Visualization Frontend
**Location**: `c:\Users\MSI\Desktop\speckit-docs-agent\speckit-docs-agent\`
**Type**: React 18 + TypeScript SPA (Single Page Application)

This project provides a modern, responsive web interface for viewing and managing PDF documents generated by the Speckit Auto-AI backend. Users can browse PDFs with rich metadata, search, filter by category, and view version history.

## Technology Stack

- **Frontend Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Routing**: React Router v6
- **State Management**: React Query (TanStack Query)
- **UI Components**: shadcn/ui (Radix UI + Tailwind CSS)
- **HTTP Client**: Axios
- **PDF Rendering**: react-pdf / PDF.js
- **Date Formatting**: date-fns
- **Testing**: Vitest + React Testing Library
- **Styling**: Tailwind CSS

## Key Design Patterns to Follow

1. **Component Testing Pattern**:
   - Mock external dependencies (hooks, routing)
   - Test user interactions (clicks, input)
   - Verify rendered output

2. **Hook Testing Pattern**:
   - Use `renderHook` from React Testing Library
   - Mock API responses
   - Test state transitions

3. **Error Handling**:
   - Test error states
   - Verify retry functionality
   - Check error messages match requirements

## Common Testing Patterns

### Mocking useParams
```typescript
import { useParams } from 'react-router-dom';
vi.mock('react-router-dom', async () => ({
  ...(await vi.importActual('react-router-dom')),
  useParams: vi.fn(() => ({ projectId: 'p1' })),
}));
```

### Mocking useArtifacts
```typescript
import { useArtifacts } from '../hooks/useArtifacts';
vi.mock('../hooks/useArtifacts');

// In test
const mockUseArtifacts = vi.mocked(useArtifacts);
mockUseArtifacts.mockReturnValue({
  artifacts: mockArtifacts,
  isLoading: false,
  error: null,
  refetch: vi.fn(),
});
```

### Testing Search Filter
```typescript
// Get search input
const searchInput = screen.getByPlaceholderText(/search/i);

// Type in search
fireEvent.change(searchInput, { target: { value: 'spec' } });

// Wait for debounce and verify filtered results
await waitFor(() => {
  expect(screen.queryByText('Other Document')).not.toBeInTheDocument();
});
```
