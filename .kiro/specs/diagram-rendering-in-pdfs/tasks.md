    - Save image to `output_dir/diagram_images/{diagram_id}.png`
    - Return Path to saved image on success, None on complete failure
    - Log warnings at each fallback level: "Mermaid.ink failed, trying Kroki...", "All services failed, skipping diagram"
    - Add unit tests for each conversion path (success and failure scenarios)
